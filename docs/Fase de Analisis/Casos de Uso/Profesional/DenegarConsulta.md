### Caso de Uso: Denegar Consulta
- **Actor principal:** Profesional
- **Resumen:** El profesional rechaza una consulta por algún motivo (falta de disponibilidad, error en los datos, etc.).
- **Precondiciones:**
  - El profesional debe haber iniciado sesión.
  - Debe haber una consulta pendiente de aprobación.
- **Flujo principal:**
  1. El profesional accede a la lista de consultas pendientes.
  2. Selecciona la consulta que desea denegar.
  3. El sistema marca la consulta como denegada y notifica al paciente.
- **Flujos alternativos:**
  - No aplica
- **Postcondiciones:**
  - La consulta queda marcada como denegada.
