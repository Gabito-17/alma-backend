### Caso de Uso: Aprobar Consulta
- **Actor principal:** Profesional
- **Resumen:** El profesional aprueba una solicitud de consulta enviada por un paciente/secretario o generada por el sistema.
- **Precondiciones:**
  - El profesional debe haber iniciado sesión.
  - Debe haber consultas pendientes de aprobación.
- **Flujo principal:**
  1. El profesional accede a la lista de consultas pendientes.
  2. Selecciona la consulta que desea aprobar.
  3. El profesional aprueba la consulta.
  4. El sistema marca la consulta como aprobada y notifica al paciente.
- **Flujos alternativos:**
  - No aplica.
- **Postcondiciones:**
  - La consulta queda aprobada y programada.
