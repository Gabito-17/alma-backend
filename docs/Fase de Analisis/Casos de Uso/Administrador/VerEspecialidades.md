## 👩‍💼 Administrador

### Caso de Uso: Ver Especialidades
- **Actor principal:** Administrador
- **Resumen:** El administrador consulta el listado de especialidades médicas disponibles en el sistema.
- **Precondiciones:**
  - El administrador debe haber iniciado sesión.
- **Flujo principal:**
  1. El administrador accede al módulo de configuración.
  2. Selecciona la opción "Ver Especialidades".
  3. El sistema muestra una lista con todas las especialidades registradas.
- **Flujos alternativos:**
  - No aplica.
- **Postcondiciones:**
  - El administrador visualiza las especialidades disponibles.
