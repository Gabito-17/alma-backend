# Documento de Planteamiento del Problema – Sistema ALMA

## Descripción general

El Policonsultorio ALMA actualmente gestiona su operación de forma desorganizada, utilizando herramientas separadas para la administración de pacientes, turnos, y registro de consultas. Esta falta de integración genera errores humanos, pérdida de información, baja eficiencia en la atención y dificultades en el seguimiento de los pacientes.

## Problemas Identificados

- Falta de centralización de la información médica.
- Gestión manual y propensa a errores de turnos y pacientes.
- Dificultad para acceder al historial clínico desde distintos dispositivos.
- Imposibilidad de automatizar recordatorios o notificaciones.
- Registro de consultas no estandarizado.

## Necesidad

Se necesita desarrollar un sistema web que unifique y automatice estos procesos, permitiendo un flujo de trabajo más ágil, seguro y accesible tanto para los profesionales como para el personal administrativo.
