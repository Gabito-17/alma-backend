# Documento de Requisitos – Sistema ALMA

## Requisitos Funcionales (RF)

- RF01: El sistema debe permitir registrar y modificar datos de pacientes.
- RF02: El sistema debe permitir registrar y modificar datos de profesionales.
- RF03: El sistema debe permitir la asignación y gestión de turnos.
- RF04: El sistema debe registrar consultas médicas y asociarlas al paciente.
- RF05: El sistema debe generar y visualizar el historial clínico.
- RF06: El sistema debe enviar recordatorios de turnos automáticamente.
- RF07: El sistema debe permitir a los administradores gestionar usuarios y roles.

## Requisitos No Funcionales (RNF)

- RNF01: El sistema debe ser accesible desde cualquier navegador moderno.
- RNF02: El acceso a los datos debe estar protegido mediante autenticación.
- RNF03: La respuesta del sistema ante acciones críticas no debe superar los 2 segundos.
- RNF04: La base de datos debe respaldarse diariamente.
- RNF05: El sistema debe cumplir con normativas de protección de datos médicos.
