# 🩺 ALMA - Sistema Integral para Policonsultorios

**ALMA** es un sistema web diseñado para mejorar la gestión integral de policonsultorios, facilitando la organización de pacientes, profesionales, turnos y consultas. Este proyecto fue desarrollado en el marco de la cátedra de Proyecto de Software (UNaM) siguiendo la metodología del Proceso Unificado (UP).

---

## 🚀 Funcionalidades principales

- Registro y autenticación de usuarios
- Gestión de pacientes y profesionales por especialidad
- Asignación, modificación y cancelación de turnos
- Agenda personalizada por profesional
- Registro de consultas y generación automática de historia clínica
- Envío automático de recordatorios de turnos
- Acceso según rol: administrativo, profesional, paciente (en futuras versiones)

---

## ⚙️ Tecnologías utilizadas

| Área             | Tecnología                |
|------------------|---------------------------|
| Backend          | [NestJS](https://nestjs.com/) (TypeScript) |
| API              | REST API               |
| Base de datos    | PostgreSQL                |
| Frontend         | [Next.js](https://nextjs.org/)|
| Arquitectura     | Cliente - Servidor        |
| Metodología      | Proceso Unificado (UP) |

## 🛠️ Instalación y ejecución

### Requisitos

- Node.js 18+
- PostgreSQL 14+
- Yarn o npm

```bash
git clone https://github.com/Gabito-17/alma-backend.git
cd alma-backend
```
